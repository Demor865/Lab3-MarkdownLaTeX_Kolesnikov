## Форматирование текста

В этом разделе показаны различные способы выделения текста:
* **Полужирный текст**
* *Курсивный текст*
* ~~Зачёркнутый текст~~
* `Моноширный текст`

> Это пример цитаты в Markdown.
> Она может занимать несколько строк.

## Списки и таблицы

### Маркированный список
- Первый пункт
- Второй пункт
- Третий пункт

### Нумерованный список
1. Первый шаг
2. Второй шаг
3. Третий шаг

### Вложенный список
- Основной пункт
  - Вложенный пункт 1
  - Вложенный пункт 2
- Второй основной пункт
