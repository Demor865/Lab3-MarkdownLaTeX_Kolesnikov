**Блоки кода**

Пример команды Git в виде inline-кода:

Команда `git commit -m "Initial commit"` создаёт коммит с сообщением.

Блок кода на языке Python:

```python
def greet(name):
    print(f"Hello, {name}!")

greet("Markdown")
```

Блок кода без указания языка:

```
Просто текст внутри блока кода.
Отступы и пробелы    сохраняются.
```
