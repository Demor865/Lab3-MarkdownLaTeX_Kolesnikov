# Введение

Markdown — это облегчённый язык разметки, созданный для написания текста, который легко читается в исходном виде и легко преобразуется в HTML. Он широко используется для оформления документации, написания статей и ведения блогов.

---

# Основные возможности Markdown

Язык предоставляет простой синтаксис для базового форматирования:
*   Заголовки разных уровней
*   Выделение текста (курсив, жирный шрифт)
*   Создание списков (маркированных и нумерованных)
*   Вставка ссылок и изображений
*   Оформление цитат и блоков кода
